# CSCS1240-F26-Study-Guides

This repository contains AI-generated study guides for CSCS1240-F26, Object-Oriented Programming with Python. The guides transform recorded classroom instruction, transcripts, and screenshots into comprehensive teaching references and compressed technical study companions.

Each guide emphasizes Python syntax, line-by-line code explanations, worked examples, execution tables, debugging techniques, and key programming concepts. The objective is to make classroom material easier to understand, practice, and review through compression without sacrificing technical depth.

All study guides are available in editable Markdown and print-ready PDF formats.

## How to Use the Study Guides

### PDF Study Guides

- Read electronically on a computer, tablet, or other device, or print for offline study.
- Follow along with the recorded classroom videos using the study guides as a companion reference.
- Review Python syntax, annotated code examples, execution tables, and key programming concepts.
- Use the guides when practicing programming, completing assignments, or preparing for exams.

### Markdown Study Guides

- Open and edit the Markdown files to create your own personalized study guides.
- Upload the Markdown files to your preferred AI model, such as ChatGPT, Gemini, or NotebookLM.
- Ask the AI to expand explanations, condense material, clarify difficult concepts, generate additional programming examples, or create practice questions.
- Customize the instructional content to match your individual learning style and level of understanding.

### Supplemental Technical Companions

The supplemental guides provide a more compact, code-focused learning resource while retaining technical depth.

They are available in both Markdown and PDF formats and can be used in the same ways as the comprehensive study guides. They are particularly useful for practicing Python, reviewing syntax, understanding program execution, and reinforcing programming concepts without rereading the entire master guide.

Use the comprehensive study guides for deeper understanding and the supplemental companions for focused technical study and review.
